# DocuBrain On-Premises Deployment Guide

Этот пакет предназначен для Enterprise-клиентов тарифа **On-Premises ($1 500 разово)** с высокими требованиями к безопасности и изоляции данных (Data Residency, GDPR, отсутствие передачи внутренней документации в сторонние облака).

## Архитектура On-Premises решения

1. **DocuBrain App**: ядро Next.js с интерфейсом управления базой знаний, подключением ботов и аналитикой.
2. **Qdrant (Self-Hosted)**: векторная база данных, запущенная локально на вашем сервере.
3. **PostgreSQL 16**: хранилище метаданных, логов запросов и неотвеченных вопросов внутри вашего периметра.

## Требования к серверу

- ОС: Ubuntu 22.04 LTS / Debian 12 / RHEL 9
- CPU: от 4 vCPU
- RAM: от 8 GB RAM
- Диск: от 50 GB NVMe SSD
- Установленный Docker и Docker Compose v2

## Быстрый запуск

1. Склонируйте репозиторий или распакуйте архив:
   ```bash
   cd on-premises
   ```

2. Создайте файл `.env`:
   ```bash
   cp .env.example .env
   # Укажите ваш GEMINI_API_KEY и придумайте безопасные пароли
   ```

3. Запустите контейнеры:
   ```bash
   docker compose up -d
   ```

4. Откройте панель управления в браузере: `http://<IP_сервера>:3000`.

## Гарантии безопасности данных

- **Изоляция векторов**: все векторы сохраняются исключительно на локальном томе `./qdrant_storage`.
- **Без внешнего сохранения документов**: исходные тексты регламентов не передаются сторонним сервисам, кроме обращения к LLM с изолированным контекстом в момент генерации ответа.
- **Шифрование токенов**: токены Telegram и Slack хранятся в БД в зашифрованном виде (AES-256).
- **Полное удаление**: при удалении документа из базы знаний все его векторные фрагменты удаляются немедленно.
